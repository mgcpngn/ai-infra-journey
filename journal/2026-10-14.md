# 2026-10-14：第 2 步，loss 与梯度到底在干什么

## 被纠正的误解

| 我原来以为 | 实际上 |
| --- | --- |
| 算 loss 就是在找 w、b | loss 只给当前参数打分；找参数的是梯度和更新 |
| loss 很神奇，知道正确的 w、b | loss 只知道每条数据的正确答案 y，拿预测和它比 |
| 第一步用「预测的」w、b | 用「当前的」w、b，预测出来的是 y |
| 反向传播会调整 w、b | 反向传播只算梯度，更新那一步才改参数 |
| 训练让 loss 趋向 0 | 让 loss 最低。有噪声时到不了 0，验证集 loss 不降就该停 |
| 梯度调整是把预测调小 | 是让预测往已知的 y 靠拢，方向由梯度正负号决定 |

## 自己总结的训练流程

> 前向（用当前参数算预测）→ 算 loss（和已知答案比）→ 反向传播（算出每个参数该往哪调）→ 更新（真的调一下），循环到 loss 不再下降。

## 对 LLM 的新理解

LLM 就是一个有几十亿到几千亿个参数的函数，每个参数都和 w、b 一样是个数。loss 地形是一个凹凸不平的巨大曲面，「知识」是训练最后停下来的那个点，也就是那一组参数值。光有直线拼不出曲面，所以需要激活函数。

## 下午：用神经网络实验台把概念理清楚

做了一个[神经网络实验台](../labs/nn-playground.html)，在网页里实时训练 2→hidden→3 的小网络。又被纠正了一批理解：

| 我原来以为 | 实际上 |
| --- | --- |
| 训练只有前向、反向、更新三步 | 四步：前向、算 loss、反向、更新。推理只做第一步，因为推理时没有正确答案 |
| ReLU 是单独的一层 | ReLU 是隐藏层的一部分，没有参数，只是把负数变 0 |
| 开不开 ReLU 差别不大 | 三团用直线就能分开所以没差别；同心圆和螺旋没有 ReLU 卡在约 39% |
| hidden=128 是 128 个参数或 128 层 | 是 1 层里有 128 个神经元，每个神经元带 785 个参数 |
| 输入层也是神经元，每个神经元 2 个参数 | 输入只是数，没有参数。每个神经元的参数 = 看几个输入就几个 w，再加 1 个 b |
| hidden_size 就是神经元个数 | LLM 里 hidden_size 是每个 token 用多少个数表示；MLP 的神经元个数是 intermediate_size |
| 把 embedding 和输出层放客户端就能保护 prompt | embedding 是查表，服务器有同一张表能直接反查；输出层服务器也能自己乘 |

## 自己总结的

- 神经元是公式，参数是公式里的数。
- ReLU 让每个神经元切一刀、压掉一半，很多刀拼起来就能围出圆和螺旋。
- 过拟合 = 神经元多、数据少，在背题。看验证 loss，掉头就停。
- 训练集 99.38% 不算数，验证集 97.93% 才是真实水平。

第 2 步过关，下一步唐诗 bigram。

## 晚上：第 3 步过关，第 4 步小 GPT 跑起来了

- **bigram（第 3 步）**：6700 万参数，验证 loss 停在 6.44。练 50000 步和 5000 步差不多，因为它只看前一个字，能学的东西早就学完了。
- **纠正**：我以为"生成要一个字一个字来是因为没有注意力"。其实是因为每个输出是下一步的输入，有注意力的 GPT 生成时也一样是串行的；训练和 prefill 才能并行。
- **小 GPT（第 4 步）**：1700 万参数，只有 bigram 的 1/4，验证 loss 降到 4.78（bigram 6.44）。3500 步之后验证 loss 开始回升，轻微过拟合。
- 训练每秒 8～10 万 token，生成每秒约 100 个字。
