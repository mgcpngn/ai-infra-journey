# 第 1 步提示词

发给 Claude Code 的原始提示词：

```
我是机器学习新手，想通过动手实验理解「训练」是什么。
请用 Python + PyTorch 写一个单文件脚本 linear_fit.py：
1. 生成 100 个点，y = 3x + 2 加一点噪声。
2. 参数 w、b 从 0 开始，用均方误差损失和梯度下降训练 200 步。
3. 先手动算梯度写一版，再用 PyTorch 自动求导写一版，证明两者结果一致。
4. 每 20 步打印 w、b、loss；最后画出 loss 曲线。
5. 把学习率做成命令行参数，方便我分别试 0.001、0.1、1.5。
每一段代码都用中文注释解释它在做什么、为什么这样做。
```

## 复盘：下次会怎么改

第一次跑完代码后完全没感觉，因为提示词只要了代码，没要讲解。之后所有提示词开头都会加一句：

> 先用大白话讲这个实验在干什么、每个参数的含义，再写代码。
