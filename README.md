# AI Infra 学习之路：从零手搓模型到推理集群

一个没有机器学习基础的人，用「提示词让 AI 写代码、自己跑实验、用自己的话讲出原理」的方式，系统学习大模型推理基础设施（AI Infra）的完整记录。

**最终目标**：懂 LLM 推理链路怎么走、瓶颈在哪、方案好坏怎么判断，能针对不同场景设计 PD 分离、评估推理平台、搭建推理集群，并能对客户讲清楚。

**学习方式**：代码交给 Claude Code 写，我负责三件事：

1. 写提示词，让 Agent 实现实验
2. 亲手跑，至少改一个参数，观察会发生什么
3. 用自己的话讲出现象背后的原理，接受追问，答得上来才算过关

所以这个仓库里最重要的不是代码，而是每一步的**笔记**：我问了什么、哪里理解错了、怎么被纠正的。

## 路线图

### 第 0 阶段：手搓一个模型，从训练到推理（约 4 周）

在 4060 上从零做出一个会写唐诗的小 GPT，再把它的推理优化一遍。每一步都在上一步的基础上长出来。

| 步 | 主题 | 要搞懂的问题 | 和推理 Infra 的关系 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | [梯度下降拟合直线](stage0/01-linear-fit/) | 参数、loss、梯度、学习率 | 模型就是一堆数字，推理只用它们做前向计算 | ✅ 已过关 |
| 2 | [两层神经网络识别手写数字](stage0/02-mnist-mlp/) | 多层、激活函数、反向传播 | 每一层都是矩阵乘（GEMM），推理最主要的算子 | ✅ 已过关 |
| 3 | [唐诗 bigram 语言模型](stage0/03-bigram/) | token、预测下一个字、softmax、采样 | 一次只出一个 token，这就是 decode 循环 | 🔄 进行中 |
| 4 | 小 GPT（约 1000 万参数） | 自注意力、为什么能看长上下文 | attention 显存随长度平方增长，FlashAttention 要解决的问题 | ⏳ |
| 5 | 给自己的模型做推理优化 | KV cache、prefill/decode、batch、量化 | TTFT、TPOT、吞吐的来源 | ⏳ |
| 6 | LoRA 微调 Qwen3-0.6B | 预训练、全量微调、LoRA | 客户常要部署微调模型，vLLM 可挂 LoRA | ⏳ |
| 7 | DPO 对齐 | SFT、RLHF、DPO、GRPO | 推理模型的长思考链，decode 占大头的来源 | ⏳ |

### 第 1 月：一张推理全景图 + 会读指标

推理链路与核心指标、盯透 vLLM 的架构与旋钮、基线压测与看曲线判瓶颈、昇腾 vs NVIDIA 对照清单。

### 第 2 月：算子与 PD 分离

常见算子各自卡在哪里、PD 分离何时划算、两种场景的调优对照表。

### 第 3 月：平台评估与集群方案

评测协议、选型矩阵与红线条款、最小集群拓扑、一份完整的假想客户方案。

## 给想用同样方法学习的人

每一步的 `prompt.md` 都可以直接发给 Claude Code 或其他编程 Agent。建议在提示词开头加一句：

> 先用大白话讲这个实验在干什么、每个参数的含义，再写代码。

然后一定要自己改一个参数再跑一次。只看代码跑通，是学不会的。
