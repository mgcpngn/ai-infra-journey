# 加字实验：唐诗 → 唐诗 + 宋诗

目的：只改训练用的字数，看验证 loss、过拟合和生成质量怎么变。

```
目标：把训练集从唐诗扩大到唐诗+宋诗，看验证 loss 和生成质量怎么变。
1. 从 GitHub 仓库 chinese-poetry/chinese-poetry 下载宋诗（全唐诗目录下 poet.song.*.json）。
2. 原文是繁体，用 opencc 转成简体，和现有唐诗数据保持一致。
3. 统计并打印：现有唐诗多少首、多少字；宋诗多少首、多少字；合并后的字表大小。
4. 每首诗之间用换行分隔。验证集只用唐诗，和之前的验证集保持一致，这样 loss 才能直接比较。
5. 给 gpt_tang.py 加参数 --data tang 或 --data tang+song。
6. 用 6 块、10000 步，各跑一次 tang 和 tang+song，打印每 1000 步的训练 loss 和验证 loss，最后各生成 5 首诗。
7. 把两次的结果整理成一张表，写入 results_data.md。
```

预测：加宋诗后过拟合推迟，最低验证 loss 低于 4.775，诗更通顺，但仍达不到"能用"。
真正"像样的诗"要靠第 6 步：在已学过中文的 Qwen3-0.6B 上用 LoRA 教唐诗写法。
