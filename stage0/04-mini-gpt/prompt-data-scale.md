# 加字实验：唐诗 → 唐诗 + 宋诗

目的：只改训练用的字数，看验证 loss、过拟合和生成质量怎么变。

```
目标：在唐诗上加入宋诗训练，和已有的唐诗结果对比。只训练一次。
1. 从 GitHub 仓库 chinese-poetry/chinese-poetry 下载宋诗（全唐诗目录下 poet.song.*.json）。
2. 原文是繁体，用 opencc 转成简体，和现有唐诗数据保持一致。
3. 打印：唐诗多少首、多少字；宋诗多少首、多少字；合并后的字表大小。
4. 每首诗之间用换行分隔。验证集必须和之前完全相同（只用唐诗那部分），这样 loss 才能直接比较。
5. 给 gpt_tang.py 加参数 --data tang 或 --data tang+song，默认 tang。
6. 只跑一次：--data tang+song --n-layer 6 --steps 5000，每 500 步打印训练 loss 和验证 loss，最后生成 5 首诗。
7. 训练前先估算总耗时并打印出来。
```

（v2：用户指出 v1 计算量太大。对照组直接用已有的 6 块 5000 步唐诗结果；加字不改变每步计算量，约 30 分钟。）

预测：加宋诗后过拟合推迟，最低验证 loss 低于 4.775，诗更通顺，但仍达不到"能用"。
真正"像样的诗"要靠第 6 步：在已学过中文的 Qwen3-0.6B 上用 LoRA 教唐诗写法。
