# 第 2 步提示词

## 主实验

```
先用大白话讲这个实验在干什么、每个参数的含义，再写代码。
我是机器学习新手，刚学完用梯度下降拟合直线。现在想理解「神经网络」。
请用 PyTorch 写 mnist_mlp.py：
1. 用 MNIST 手写数字数据集，训练一个两层神经网络（784 → 128 → 10），在 GPU 上跑。
2. 加一个命令行开关 --no-act，去掉中间的激活函数（ReLU），方便我对比。
3. 每个 epoch 打印训练集和验证集的 loss 与准确率，最后画出两条 loss 曲线。
4. 打印模型参数总数，以及参数占多少字节。
5. 分别计时：训练一个 batch 用多久，只做前向推理一个 batch 用多久。
```

## 补充：让参数量和耗时一眼可见

第一次跑完看不出参数量和耗时比，补了这段：

```
在 mnist_mlp.py 里加两处输出，不改其他逻辑：
1. 训练开始前，逐层打印：层名、权重形状、偏置形状、该层参数量，最后打印总参数量。
2. 训练结束后，用同一个 batch 各测 100 次取平均，打印一行：
   「训练一个 batch：X ms，推理一个 batch：Y ms，比值：Z」
   推理要放在 torch.no_grad() 里，计时前后都要 torch.cuda.synchronize()。
再加一个参数 --hidden，让我可以把中间层改成 16、128、512 对比。
```
