# 手动跑 lora_poem.py：怎么运行、看哪一行、改哪个参数

写于 10-20。代码是 [lora_poem.py](lora_poem.py)，下面的行号都指这个文件。

## 1. 怎么运行

在 WSL 终端里输入：

```
cd /home/wangli/step1
python lora_poem.py
```

下载模型慢时，改用：

```
HF_ENDPOINT=https://hf-mirror.com python lora_poem.py
```

它会按顺序跑 4 个实验（文件第 3～7 行写着）：基线、全量微调 5 步、LoRA r=8 训练 1000 步、r=2 和 r=32 各训练 300 步。全部跑完要十几分钟（推测，没计时）。结果最后写进 `results_lora.md`。

## 2. 屏幕上看哪一行

LoRA 训练时，每 100 步打印一行（代码第 267 行）。样子是：

```
r=8 step 100  训练 loss=4.2406  验证 loss=4.1165  370 ms/步  显存峰值 5.08 GB
```

- `step 100`：已经训练了 100 步。
- `370 ms/步`：这 100 步平均每步花的时间。**「LoRA 训练一步约 370 ms」就是从这里来的**，也写在 results.md 的「训练过程」表里（第 100 步 370，第 200 步 361……）。
- `显存峰值 5.08 GB`：训练到现在显存最多用了多少。

## 3. 关键参数在哪一行

| 参数 | 现在的值 | 在哪一行 | 改它会怎样（先猜，再跑） |
|---|---|---|---|
| 每一步读几首诗（batch） | 16 | 第 256 行 `torch.randint(len(Xtr), (16,), ...)` 里的 `16` | 每步时间、显存 |
| 每首诗最长多少 token | 64 | 第 28 行 `L = 64` | 每步时间、显存、被截断的诗有多少 |
| 学习率（步子大小） | 2e-4 | 第 232 行 `lr=2e-4`（第 246 行也有，但每步会被第 255 行按第 232 行的曲线覆盖） | loss 降得快不快、稳不稳 |
| 训练多少步 | 1000 | 第 275 行 `train_lora(8, 1000, ...)` 里的 `1000` | 总时间、最后的 loss |
| LoRA 的 r | 8 | 第 275 行 `train_lora(8, ...)` 里的 `8` | 要训练的参数个数、显存 |
| LoRA 挂在哪几张表 | q k v o | 第 243 行 `target_modules=[...]` | 要训练的参数个数 |

注意：第 275 行的步数不要改小于 1000。第 282 行要用第 1000 步生成的诗，改小会报错。

## 4. 一次只改一个参数

规则：每次只改上表里的一个数，其它都不动；改之前先写下猜测。
