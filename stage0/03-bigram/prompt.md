# 第 3 步：唐诗 bigram 语言模型

## 这一步要搞懂的
- token 和词表：文字怎么变成模型能算的数
- "预测下一个字"：LLM 训练的唯一任务，标签来自文本本身
- 采样和 temperature：模型输出的是概率，怎么从概率里挑字
- 一次只出一个字：这就是推理里的 decode 循环

## 给本机 Claude Code 的提示词

```
先用大白话讲这个实验在干什么、每个参数的含义，再写代码。

我想用 PyTorch 在我的 RTX 4060 上做一个"只看前一个字、猜下一个字"的最简单语言模型（bigram），用唐诗训练。要求：

1. 数据：下载一份唐诗纯文本（例如 chinese-poetry 项目里的全唐诗，繁体转简体），整理成 data/tang.txt，每首诗一行。下载不了就停下来告诉我，我手动放文件。打印总字数。
2. 词表：统计所有出现过的字，建立"字→编号"和"编号→字"两张表，打印词表大小和出现最多的 20 个字。
3. 模型：只有一张"词表大小 × 词表大小"的表（nn.Embedding）。第 i 行就是"前一个字是 i 时，下一个字各自的分数"。打印参数量和占多少 MB。
4. 训练前：打印"如果完全瞎猜，loss 应该是多少"（ln 词表大小），再实际算一次未训练模型的 loss 对比。
5. 训练：随机取连续的文本片段，输入是每个字，标签是它后面那个字，用交叉熵和 AdamW。90% 训练、10% 验证，每隔一段打印训练和验证 loss。
6. 生成：给一个开头的字，按概率一个字一个字往下采样，生成 5 首。训练前生成一次、训练后再生成一次，对比。
7. 加 --temperature 参数（默认 1.0）控制采样的随机程度，加 --steps 控制训练步数。
```

## 跑完后要能回答的问题
1. 词表大小是多少？模型参数量是多少？为什么参数量正好是词表大小的平方？
2. 训练前的 loss 为什么接近 ln(词表大小)？
3. 训练后生成的诗为什么每两个字之间读得通，整句却不通？
4. temperature 调成 0.1 和 2.0，生成的诗各有什么变化？为什么？
5. 生成 1 首 20 字的诗，模型要做几次前向？这和 LLM 推理的 decode 有什么关系？
