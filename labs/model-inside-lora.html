模型里面长什么样

三个部分。每部分先动手看，再读名字。名字都折在每部分最后。

第 1 部分 · 一张表在做什么

3 个数进去，2 个数出来

左边是进来的 3 个数。中间是一张格子，格子里是参数。右边是出来的 2 个数。电脑负责算，你只看谁跟着谁动。

→
格子（参数）
旁边的小路（LoRA） 3 个数 → 1 个数 → 2 个数
任务
  1. 拖第 1 个进来的数。右边哪个出来的数动了？
  2. 点「接上旁边的小路」。格子里的数变了吗？出来的数变了吗？
  3. 再点一次，关掉小路。出来的数回到哪里？
  4. 接上小路后，点「合并」。小路去哪了？格子变了吗？出来的数变了吗？
看名字

这种格子叫 表。一张表把一组数变成另一组数。每个出来的数，都是按格子里的比例，把进来的数混在一起。

表里的格子就是 参数。训练改的就是这些格子。

Qwen3 的 q_proj 就是这样一张表，只是更大：1024 个数进去，2048 个数出来，格子有 2,097,152 个。

小路就是 LoRA：进来的数先挤成很少几个数（Qwen3 里是 8 个），再放回原来的个数，最后加到大表的结果上。

第 2 部分 · 一个字从进到出

「落」字走一遍 Qwen3-0.6B

点「走一遍」，看亮的位置往下走。然后点任意一个「层」，看它里面有什么。

每一层里面（28 层都一样，只是格子里的参数不同）

前半：注意力 这个字去看句子里的别的字，取信息

q_proj 1024 → 2048 个数，叫 Q：我要找什么 LoRA 挂这里
k_proj 1024 → 1024 个数，叫 K：我是什么 LoRA 挂这里
v_proj 1024 → 1024 个数，叫 V：我能提供什么 LoRA 挂这里
用这个字的 Q 去和前面每个字的 K 比，越像越关注，再按关注多少取它们的 V（这一步没有表）
o_proj 2048 → 1024 个数，把取到的信息整理回 1024 个 LoRA 挂这里
结果加回到这个字原来的 1024 个数上。每层只改一点，不推倒重来。

后半：MLP 这个字自己想一想，不看别的字

gate_projup_proj 1024 → 3072 个数
down_proj 3072 → 1024 个数
结果也加回到原来的 1024 个数上。
任务
  1. 走一遍时，一个字在每一层之间一直是多少个数？
  2. q_proj 是一层吗？还是一层里面的一样东西？
  3. 点「显示 LoRA 挂在哪」。LoRA 自己占了一层吗？
看名字

课本上的画法是「输入层 → 隐藏层 → 输出层」。对到 Qwen3：

输入 = 查字表，把「落」换成 1024 个数。

中间 = 28 个 层（课本叫隐藏层，我们的词表统一叫「层」）。每层 = 注意力 + MLP。

输出 = 打分：把最后的 1024 个数变成字表里 151,936 个 token 各一个分数，分数最高的最可能是下一个字。

q_proj 不是一层。它是每一层注意力里的第一张表。一层里有 7 张大表（q k v o + gate up down）。

第 3 部分 · LoRA 串在前面，串在后面，还是并排

放大看一张 q_proj

点「接上 LoRA」，看点点从哪里分开，又在哪里汇合。

现在：只有大表
任务
  1. 小路的点点在大表前面出发，还是从大表后面出发？
  2. 大表里的格子，接上 LoRA 以后被改了吗？（回想第 1 部分）
  3. 为什么拔掉小路，结果和原模型一个数都不差？
看名字

LoRA 不串在前面，也不串在后面，是 并排：同一份进来的数，同时走大表和小路，两份结果在加号处相加。

大表一个格子都没改。所以拔掉小路，就只剩大表，结果就和原模型一样。这就是 lora_peek 第 3 段「关掉」和「原模型」完全相同的原因。

第 6 步在每一层的 q、k、v、o 四张表旁边各挂一条小路。28 层 × 4 张 = 112 条小路，加起来 2,293,760 个数。

合并 = 把小路的效果直接加进大表的格子，然后扔掉小路。所以合并后又是一张普通的表，参数个数回到 596,049,920。
